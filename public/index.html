Personal Finance Tracker

Vos finances, avec une vue plus claire.

Un assistant privé pour consulter les comptes, comprendre les dépenses et examiner les paiements récurrents avec ChatGPT. Ce projet personnel n’est pas une application officielle de BNP Paribas Fortis, Revolut ou Enable Banking.

Lecture seule

Aucun paiement ni virement ne peut être créé.

Historique privé

La v2 prévoit un stockage local protégé sur le VPS. Aucune donnée financière n’est publiée sur ce site.

Analyses expliquées

Les estimations sont distinguées des faits. Les données incomplètes ou anciennes sont signalées.

La v2 doit être validée et activée par son propriétaire avant utilisation. Ce site ne permet pas d’ouvrir un compte ni de connecter une banque.
