Your own instance

Renew bank access.
On your private server.

Already running Finance Tracker? Open your own server to renew BNP Paribas Fortis or Revolut access. This GitHub Pages site is an entry point; it hosts no banking service and receives no bank credentials, codes or financial data.

For example, https://finance.your-domain.example — only the server address, without a path, password, code or callback link.

Enter the address of a server you control.

Check the address before confirming. Only its HTTPS origin is saved in this browser, without secrets. No payment or central storage is added by this page.

Sign in on your own server

Your server asks for its private login, then shows the bank renewal buttons. Bank consent takes place through Enable Banking and your bank. Never enter a banking password on this static site or share a callback URL in a chat.

Each instance belongs to its owner

Each user owns and configures their VPS, Enable Banking application, credentials and encrypted history. This page cannot activate an unconfigured server. Your private web interface must already be securely configured and running.

Need to prepare your instance? Read the private renewal setup notes.
