Three steps, with clear boundaries. Your server stores the history; ChatGPT queries it through read-only MCP tools.

01

Run it on your machine

Install the Python server on your computer or VPS. Configure your own Enable Banking application and authorize your accounts.

02

Sync to encrypted storage

Sync transactions into a local encrypted database. Keep the encryption key separate and check when your data was last refreshed.

03

Ask ChatGPT, in read-only mode

Connect through a private MCP tunnel. ChatGPT can query the cached data, with no tools to make payments or move money.
